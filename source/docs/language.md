# Анализ тональности твитов

# КЛАССИФИКАЦИЯ ТВИТОВ ПО ТОНАЛЬНОСТИ

## ОПИСАНИЕ

В данной лабораторной работе была решена задача классификации твитов по тональности с использованием методов машинного обучения. Были рассмотрены положительные и отрицательные твиты, выполнена предобработка текстовых данных, построены и сравнены несколько моделей классификации, после чего была выбрана модель, показавшая наилучший результат.

## ОСНОВНЫЕ ВОЗМОЖНОСТИ

* Загрузка и анализ набора данных с положительными и отрицательными твитами.
* Объединение данных в один датафрейм.
* Разделение выборки на обучающую и тестовую части.
* Предобработка текстовых данных.
* Векторизация текста с помощью CountVectorizer.
* Обучение модели Logistic Regression.
* Обучение модели XGBClassifier.
* Обучение модели MultinomialNB.
* Векторизация текста с помощью TF-IDF.
* Проверка качества моделей на униграммах, биграммах, триграммах и пентаграммах.
* Оценка качества моделей с помощью precision, recall, f1-score и accuracy.
* Сравнение результатов и выбор лучшего варианта векторизации.

## РЕЗУЛЬТАТЫ

В ходе работы были получены следующие результаты:

* Logistic Regression была использована как базовая модель классификации текста.
* XGBClassifier был применен как альтернативный алгоритм машинного обучения.
* MultinomialNB был использован как второй альтернативный алгоритм, хорошо подходящий для текстовой классификации.
* При использовании TF-IDF лучший результат показали униграммы.
* Для униграмм значение accuracy составило 0.76, а weighted f1-score также составил 0.76.
* Биграммы показали более слабый результат: accuracy = 0.71, weighted f1-score = 0.71.
* Триграммы дали accuracy = 0.65 и weighted f1-score = 0.64.
* Пентаграммы показали самый низкий результат: accuracy = 0.56 и weighted f1-score = 0.45.

Наиболее эффективным вариантом оказалась модель Logistic Regression с TF-IDF-векторизацией и униграммами.

## ВЫВОД

В ходе лабораторной работы были изучены методы обработки текстовых данных и классификации твитов по тональности. Были построены и сравнены разные модели машинного обучения, а также проверено влияние размера n-грамм на качество классификации.

Лучший результат показала TF-IDF-векторизация с униграммами. Увеличение размера n-грамм не улучшило качество модели. Наоборот, биграммы, триграммы и пентаграммы показали более низкий результат. Это связано с тем, что длинные последовательности слов встречаются в текстах реже, из-за чего матрица признаков становится слишком разреженной.

Таким образом, для данной задачи лучше всего использовать Logistic Regression вместе с TF-IDF-векторизацией отдельных слов.
