# ПРОГНОЗИРОВАНИЕ СТОИМОСТИ НЕДВИЖИМОСТИ

## ОПИСАНИЕ

В данной лабораторной работе была решена задача прогнозирования стоимости недвижимости с использованием методов машинного обучения. Были построены и сравнены несколько регрессионных моделей, после чего выбрана модель, показавшая наилучший результат.

## ОСНОВНЫЕ ВОЗМОЖНОСТИ

- Загрузка и анализ набора данных.
- Построение модели линейной регрессии.
- Удаление малозначимых признаков.
- Обучение модели Random Forest Regressor.
- Обучение модели Gradient Boosting Regressor.
- Оценка качества моделей с помощью метрик MAE, MSE и RMSE.
- Сравнение результатов и выбор лучшей модели.

## РЕЗУЛЬТАТЫ

В ходе работы были получены следующие результаты:

- Линейная регрессия показала базовое качество прогнозирования.
- Удаление признаков «Количество этажей», «Год реновации» и «Спальни» практически не повлияло на точность.
- Random Forest Regressor показал наименьшую ошибку.
- Gradient Boosting Regressor также продемонстрировал высокий результат.

Наиболее эффективной моделью оказался Random Forest Regressor.

## ИСПОЛЬЗОВАННЫЕ ТЕХНОЛОГИИ

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## ВЫВОД

В ходе лабораторной работы были изучены методы регрессии для прогнозирования стоимости недвижимости. Были построены и сравнены три модели машинного обучения. Лучший результат показала модель Random Forest Regressor, которая обеспечила минимальную ошибку предсказания.
